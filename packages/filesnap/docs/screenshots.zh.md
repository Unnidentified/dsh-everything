# 截图与历史版本

当前展示使用插件 **0.4.0**、引擎 **0.5.1** 和 DSH **0.1.2-rc.1（a66e470）**。拍摄日期：2026-09-11。

以下为隔离工作区中实际运行的中文 Web UI，分辨率 1440 × 1000。会话文案为手工编写的演示样例；会话文件、引擎快照、回退、redo 预览和存储数据均为真实操作结果，未模拟接口或拼接界面。中断恢复通过临时进程在文件还原前主动退出产生；迁移样例关闭自动迁移，保留旧标记供扫描。
