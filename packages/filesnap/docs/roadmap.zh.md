# 路线图

[README](../README.md) · [English](roadmap.md)

## 0.3.0 已实现

- 回退前文件清单与二次确认，确认时重新检查文件状态。
- 独立工作区快照面板：索引与共享内容占用、会话快照数量、未保护文件。
- 手动确认清理未引用数据，保留快照和 redo 救援数据。
- 设置中的多版本迁移入口，首个任务修复旧会话卸载兼容性。
- 不再写自定义会话事件；浏览器按钮走独立 RPC。
- 原始提示词回填空输入框。

## 后续计划

| 优先级 | 改进 | 边界 |
|---|---|---|
| P1 | 保留策略与可选自动清理 | 时间、数量、存储限额和受保护会话；需要明确预览将失去的恢复点。 |
| P1 | 会话快照删除与存储健康检查 | 当前清理只回收未引用对象；尚无会话删除和引擎 doctor 的界面。 |
| P1 | 逐行内容 diff | 当前预览展示路径与动作。 |
| P2 | 仅回退对话 | 定义文件不变时的分支与 redo 行为。 |
| P2 | 逐文件恢复 | 明确局部恢复后的对话/文件一致性限制。 |
| P2 | 更完整的快捷键与命令导航 | 现有对话框支持 Esc、Tab、Enter；没有新的全局快捷键。 |

以上是计划，不是已提供的能力或发布日期承诺。迁移新数据格式时继续复用[统一入口](migrations.zh.md)，为对应数据源增加适配与测试。
