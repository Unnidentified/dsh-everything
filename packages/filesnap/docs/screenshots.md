# Screenshots and historical versions

Current images show plugin **0.4.0**, engine **0.5.1**, and DSH **0.1.2-rc.1 (a66e470)**, captured on 2026-09-11.

These are actual Chinese Web UI screenshots at 1440 × 1000, using an isolated workspace. Conversation text is a hand-authored demo fixture; native session files, engine snapshots, rewind, redo previews and storage figures come from real operations. No RPC mocking or composited UI is used. The recovery fixture deliberately exits a temporary process before restoration. Automatic migration is disabled in the demo so legacy markers remain available for scanning.
